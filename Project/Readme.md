# TSID для PostgreSQL

Расширение добавляет тип данных `tsid` — компактный 64‑битный идентификатор, генерируемый на основе времени, номера узла и счётчика. Идентификаторы имеют строковое представление длиной 13 символов в безопасном алфавите (без неоднозначных символов). Тип поддерживает специальное «пустое» значение (`EMPTY`), а также сравнения с типами `text` и `bigint`.

## Особенности

- 64‑битный размер, занимает 8 байт в таблице (фиксированный, passed by value).
- Пустое значение (`EMPTY`) представляется числом 0 и выводится как пустая строка.
- Генерация включает:
  - 42 бита времени (миллисекунды с 2020‑01‑01)
  - 10 бит ноды (задаётся через GUC `tsid.node_id`)
  - 12 бит счётчика (увеличивается атомарно)
- Строковое представление — base32 с алфавитом без неоднозначных символов (I, L, O, U исключены).
- Функции преобразования в верхний/нижний регистр, десятичный и шестнадцатеричный формат.
- Функции извлечения информации:
  - `node_id(tsid)` — возвращает номер ноды, из которого был сгенерирован идентификатор.
  - `datetime(tsid)` — возвращает временную метку создания идентификатора (тип `timestamptz`).
- Операторы сравнения для `tsid` с `tsid`, `text` и `bigint`.
- Поддержка B‑tree и hash индексов.

## Установка

### Требования

- PostgreSQL 16 (другие версии можно адаптировать)
- Права суперпользователя для установки расширения

### Сборка из исходников

```bash
git clone <репозиторий>
cd tsid
make
sudo make install
```

### Установка расширения в базе данных

```sql
CREATE EXTENSION tsid;
```

## Настройка ноды

Номер ноды задаётся через GUC-параметр `tsid.node_id`. Допустимые значения: от 0 до 1023.

```sql
-- Установить для текущей сессии
SET tsid.node_id = 42;

-- Установить для всей базы (требует перезагрузки)
ALTER SYSTEM SET tsid.node_id = 42;
SELECT pg_reload_conf();
```

По умолчанию `node_id = 0`.

## Тип данных `tsid`

### Создание таблицы с tsid

```sql
CREATE TABLE documents (
    id tsid DEFAULT tsid() PRIMARY KEY,
    parent tsid,           -- может быть NULL или EMPTY
    title text
);
```

### Литералы и приведение

```sql
-- Пустое значение
SELECT ''::tsid;

-- Обычный tsid из строки
SELECT '0AJH5XWZQ1B2C'::tsid;

-- Приведение из bigint (числовое значение)
SELECT 12345::tsid;
```

## Функции

### Генерация новых идентификаторов

| Функция          | Возвращает       | Описание                          |
|------------------|------------------|-----------------------------------|
| `tsid()`         | `tsid`           | Генерирует новый tsid             |
| `tsid_upr()`     | `text`           | Новый tsid в верхнем регистре     |
| `tsid_lwr()`     | `text`           | Новый tsid в нижнем регистре      |
| `tsid_dec()`     | `text`           | Десятичное представление нового tsid |
| `tsid_hex()`     | `text`           | Шестнадцатеричное (верхний регистр) |

Пример:
```sql
SELECT tsid(), tsid_upr(), tsid_dec();
```

### Преобразование существующего tsid

| Функция                 | Возвращает | Описание                        |
|-------------------------|------------|---------------------------------|
| `upper(tsid)`           | `text`     | Верхний регистр                 |
| `lower(tsid)`           | `text`     | Нижний регистр                  |
| `to_char(tsid, text)`   | `text`     | Форматирование: 'U','L','D','H' |
| `to_tsid(text)`         | `tsid`     | Преобразование строки в tsid    |
| `is_empty(tsid)`         | `boolean`  | Проверка, является ли tsid пустым |

Форматы для `to_char`:
- `'U'` / `'u'` — верхний регистр
- `'L'` / `'l'` — нижний регистр
- `'D'` / `'d'` — десятичное число
- `'H'` / `'h'` — шестнадцатеричное (верхний регистр)

Пример:
```sql
SELECT upper(tsid()), to_char(tsid(), 'H');
```

### Проверка на пустое значение

```sql
SELECT is_empty(''::tsid);   -- true
SELECT is_empty(tsid());     -- false
```

### Извлечение информации из tsid
| Функция                 |	Возвращает | Описание                        |
|-------------------------|------------|---------------------------------|
|node_id(tsid)	          | integer	   | Номер ноды, сгенерировавшей идентификатор |
|datetime(tsid)	          |timestamp with time zone	| Время создания идентификатора |

Примеры:

```sql
-- Получить номер ноды из сгенерированного tsid
SELECT node_id(tsid());

-- Получить время создания
SELECT datetime(tsid());

-- Для пустого значения обе функции вернут NULL
SELECT node_id(''::tsid), datetime(''::tsid);
```

Примечание: Функция datetime для пустого значения (EMPTY) возвращает NULL, так как у пустого идентификатора нет временной метки. Функция node_id для EMPTY также вернёт NULL.

## Операторы сравнения

### `tsid` с `tsid`

Обычные операторы: `=`, `<>`, `<`, `<=`, `>`, `>=`. Сравнение происходит по 64‑битному числовому значению.

### `tsid` с `text`

Значение `tsid` преобразуется в строку (верхний регистр) и сравнивается лексикографически.

```sql
SELECT tsid() = '0AJH5XWZQ1B2C'::text;
SELECT tsid() < '0ZZZZZZZZZZZZ'::text;
```

### `tsid` с `bigint`

Сравнение по числовому значению.

```sql
SELECT tsid() = 12345::bigint;
SELECT tsid() > 1000000;
```

Обратите внимание: для `bigint` операнды могут располагаться в любом порядке, например `1000 < tsid()`.

## Индексы

Тип `tsid` поддерживает стандартные B‑tree и hash индексы. Для B‑tree используется класс операторов `tsid_ops`, для hash — `tsid_hash_ops`.

```sql
CREATE INDEX ON documents USING btree (id);
CREATE INDEX ON documents USING hash (id);
```

Поскольку сравнение с `text` преобразует `tsid` в строку, индекс по столбцу `tsid` **не будет использоваться** для условий вида `tsid = text`. Рекомендуется явно приводить текст к типу `tsid`, если нужно использовать индекс:

```sql
SELECT * FROM documents WHERE id = '0AJH5XWZQ1B2C'::tsid;
```

## Примеры использования

### Генерация и вставка

```sql
INSERT INTO documents (title) VALUES ('Document 1') RETURNING id;
```

### Поиск по значению

```sql
SELECT * FROM documents WHERE id = '0AJH5XWZQ1B2C'::tsid;
```

### Поиск по диапазону

```sql
SELECT * FROM documents WHERE id between '0PRF4ANB85004' and '0PRF4G4YC5006';
```

### Использование пустого значения

```sql
-- Вставка с пустым parent
INSERT INTO documents (parent, title) VALUES (''::tsid, 'Root');

-- Выборка записей, где parent пустой
SELECT * FROM documents WHERE is_empty(parent);
-- или
SELECT * FROM documents WHERE parent = ''::tsid;
```

### Сравнение с текстовым литералом

```sql
-- Без явного приведения (работает благодаря оператору tsid = text)
SELECT * FROM documents WHERE id = '0AJH5XWZQ1B2C';
```

## Развертывание в Docker

Расширение `tsid` можно легко использовать в Docker-контейнере с PostgreSQL. Ниже приведены два способа: сборка собственного образа и запуск через `docker-compose`.

### Подготовка файлов

Создайте директорию проекта со следующей структурой:

```text
postgres-tsid/
├── Dockerfile
├── Makefile
├── tsid.c
├── tsid.control
├── tsid--1.0.sql # актуальная версия SQL
├── init.sql # скрипт инициализации (создание расширения)
├── set_node_id.sh # скрипт инициализации номера ноды
└── docker-compose.yml # опционально
```

### Сборка и запуск

```bash
docker build -t postgres-tsid .
docker run -d \
  --name postgres-tsid \
  -e POSTGRES_PASSWORD=mysecretpassword \
  -e POSTGRES_DB=mydb \
  -p 5432:5432 \
  -v pgdata:/var/lib/postgresql/data \
  postgres-tsid
  ```

### Использование docker-compose
```bash
docker-compose build --no-cache
docker-compose up -d
```

### Подключение к базе и проверка
```bash
docker exec -it postgres-tsid psql -U myuser -d mydb -c "SELECT tsid();"
```

### Внутри psql выполните:
```sql
\dx                        -- убедитесь, что расширение установлено
SELECT tsid();              -- генерация нового tsid
SELECT ''::tsid;            -- пустое значение
SELECT is_empty(''::tsid);
```

### Примечания
- В приведённых примерах используется PostgreSQL 16. Для других версий измените тег образа и название пакета postgresql-server-dev-XX.

- Если вы планируете использовать несколько контейнеров с разными нодами, задайте параметр tsid.node_id в postgresql.conf или через ALTER SYSTEM. Например, можно добавить в init.sql:
```sql
ALTER SYSTEM SET tsid.node_id TO 42;
SELECT pg_reload_conf();
```

- Для production рекомендуется использовать внешний том для данных, как показано в примерах.

## Примечания

- Пустое значение хранится как 8-байтовый ноль, поэтому занимает место. Если нужна экономия, используйте NULL.
- Генератор никогда не вернёт пустое значение.
- Алфавит исключает символы I, L, O, U для предотвращения визуальной путаницы.
- Счётчик атомарный, но не сбрасывается при смене миллисекунды — это нормально для 12 бит (максимум 4096 значений в миллисекунду на ноду).

## Лицензия

Расширение распространяется под лицензией PostgreSQL (аналогично BSD). Используйте на свой страх и риск.
