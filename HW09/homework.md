## 2. Развёртывание кластеров через веб-интерфейс

### VK Cloud

**Шаги создания:**
1. Зашёл в личный кабинет VK Cloud → Разделы → Базы данных → Создать базу данных
2. Выбрал PostgreSQL 17
3. Настроил параметры:
   - Конфигурация: **STD3-2-8** (2 vCPU, 8 ГБ RAM)
   - Диск: **SSD 10 ГБ**
   - Зона доступности: GZ1 (Москва)
   - Назначить внешний IP: ✅ включено
   - Сеть: создать новую или выбрать существующую
4. Инициализация:
   - Имя базы: `shipments`
   - Имя пользователя: `banana`
   - Пароль: `banana123`
5. Нажал "Создать"

**Результат:** кластер создан за ~3 минуты, внешний IP появился сразу: `212.233.78.145`

### Yandex Cloud

**Шаги создания:**
1. Зашёл в консоль Yandex Cloud → Managed Service for PostgreSQL → Создать кластер
2. Настроил параметры:
   - Имя кластера: `bananaflow-yc`
   - Версия: 17
   - Класс хоста: **s2.micro** (2 vCPU, 8 ГБ RAM)
   - Диск: **10 ГБ SSD**
   - Хосты: один хост с публичным доступом
   - Настройки сети: выбрать подсеть, включить публичный IP
3. Настройки БД и пользователя:
   - Имя базы: `shipments`
   - Имя пользователя: `banana`
   - Пароль: `banana123`
4. Нажал "Создать"

**Результат:** создание заняло ~7 минут. После статуса RUNNING пришлось подождать ещё ~3 минуты, пока резолвится FQDN. Получил FQDN: `rc1a-4f8k2s7h9t1l5n3m.mdb.yandexcloud.net`

## 3. Подключение и проверка

### VK Cloud
```bash
psql -h 212.233.78.145 -p 5432 -U banana -d shipments -W
```
Подключилось с первого раза.

### Yandex Cloud
```bash
# Качаем SSL-сертификат
mkdir -p ~/.postgresql && \
wget "https://storage.yandexcloud.net/cloud-certs/CA.pem" -O ~/.postgresql/root.crt

# Подключаемся
psql "host=rc1a-4f8k2s7h9t1l5n3m.mdb.yandexcloud.net port=6432 sslmode=require dbname=shipments user=banana"
```

Проверка на обоих кластерах:
```sql
CREATE TABLE test (id serial, name text);
INSERT INTO test VALUES (1, 'bananas');
SELECT * FROM test;
```
Всё работает.

## 4. Сравнение характеристик

### Стоимость в месяц

| Провайдер | Конфигурация | Стоимость (руб/мес) |
|-----------|--------------|---------------------|
| VK Cloud | 2 vCPU, 8 RAM, 10 GB SSD | **4900 ₽** |
| Yandex Cloud | 2 vCPU, 8 RAM, 10 GB SSD | **5500 ₽** |

**VK Cloud дешевле на ~11% (600 ₽ в месяц)**

---

### Производительность

Запустил тест pgbench с масштабом 100, 10 клиентами, 60 секунд:

**VK Cloud**
```

**Yandex Cloud**
```

tps = 7.22

**Результаты практически одинаковые**, но VK быстрее подключается (initial connection time 4.9 сек против 7.4 сек).

### Удобство управления

| Критерий | VK Cloud | Yandex Cloud |
|----------|----------|--------------|
| Интерфейс | Простой, интуитивный | Навороченный, много опций |
| Скорость создания | 3 минуты | 7-10 минут |
| Подключение | IP сразу (`212.233.78.145`), без SSL | Нужен SSL, долгий резолвинг |
| Документация | Хорошая, на русском | Отличная, много примеров |

---

### Проблемы, с которыми столкнулся

**VK Cloud:**
- Всё прошло гладко, проблем не было

**Yandex Cloud:**
- Долгое резолвинг DNS после создания кластера (FQDN не пинговался ~3 минуты)
- SSL-сертификат нужно качать отдельно
- Команда подключения сложнее (порт 6432, sslmode=require)
- Цена выше на 600 ₽ в месяц при одинаковых характеристиках

## 5. Вывод для BananaFlow

| Критерий | Победитель |
|----------|------------|
| Цена | VK Cloud |
| Скорость развёртывания | VK Cloud |
| Простота подключения | VK Cloud |
| Производительность | Ничья |
| Документация | Yandex Cloud |

**Для BananaFlow лучше подойдёт VK Cloud**, если:
- Бюджет ограничен (экономия 600 ₽ в месяц на одной БД)
- Нужно быстро развернуть тестовые среды
- Важна простота подключения без SSL-сертификатов

**Yandex Cloud** стоит выбрать, если:
- Планируется интеграция с другими сервисами Яндекса
- Нужна подробная документация и мониторинг
- Дополнительные 600 ₽ в месяц не критичны
