# Домашнее задание "Гонка за производительностью"

## Цель:
настроить PostgreSQL для максимальной скорости работы под нагрузкой;


## Описание/Пошаговая инструкция выполнения домашнего задания:
Компания "BananaFlow" недавно запустила новый сервис — "Банановый мониторинг".
Это инновационная платформа, которая позволяет клиентам в реальном времени отслеживать состояние своих заказов: от сбора урожая на плантациях до доставки в пункт назначения. Сервис стал невероятно популярным, особенно среди крупных сетей супермаркетов, которые хотят гарантировать свежесть продукции своим покупателям.
Однако с ростом популярности сервиса возникла проблема: база данных, которая обрабатывает миллионы запросов в минуту, начала "тормозить". Клиенты жаловались на задержки в обновлении данных.
Алексей понял, что нужно срочно оптимизировать производительность PostgreSQL. Он решил провести тюнинг базы данных, чтобы ускорить обработку запросов и вернуть доверие клиентов. Однако на пути к успеху его ждали новые вызовы:
- Как настроить PostgreSQL для максимальной производительности?
- Какие параметры нужно изменить, чтобы ускорить работу системы?
- Как проверить, что оптимизация действительно работает?

## 🎯 Задание

Повторите шаги Алексея:

1. Разверните инстанс PostgreSQL на виртуальной машине в Яндекс.Облаке или любом другом месте.
2. Протестируйте производительность с помощью pgbench.
3. Оптимизируйте настройки PostgreSQL для максимальной производительности.
4. Проверьте, насколько выросла производительность.
5. Настройте кластер на оптимальную производительность, не обращая внимания на стабильность БД.
