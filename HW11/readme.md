# Домашнее задание "Кластеры высокой доступности"

## Цель:
научиться развертывать кластер PostgreSQL с высокой доступностью в облаке или локальной среде, используя подходящие инструменты и технологии;


## Описание/Пошаговая инструкция выполнения домашнего задания:
*Алексей сидел в переговорке с чашкой остывшего кофе. На коленях у него уютно свернулся клубочком его кот — неофициальный талисман отдела инфраструктуры. Кота звали Дефолт. Он всегда мурлыкал, когда Алексей находил особенно элегантные решения.

— Алексей, — строго, но с интересом начал руководитель Олег, заходя в комнату, — ты справился с задачей по сбору датасета для тренировки. А теперь давай серьезно. Нам нужен высокодоступный кластер PostgreSQL.
*
— Один или два? — не поднимая глаз, уточнил Алексей, машинально поглаживая Дефолта.


## 🔧 Вариант 1. Кластер своими руками

1. Разверните высокодоступный кластер PostgreSQL вручную. Возможные технологии:

  - Patroni + Etcd + HAProxy
  - Pacemaker/Corosync/DRBD (для продвинутых)

2. Среда развертывания:

  - Можно использовать виртуальные машины в локальной сети (например, через VirtualBox, Proxmox)


## ☁️ Вариант 2. HA-кластер в облаке

1. Разверните кластер PostgreSQL с высокой доступностью с использованием одного из облаков, например:

  - Yandex Managed Service for PostgreSQL (если нужна управляемая БД)
  - Развертывание вручную в Yandex Cloud Compute
  - VK Cloud, Timeweb Cloud, Selectel, ROSA Cloud и др.

## ⭐ Для гурманов (повышенная сложность)

1. Разверните два кластера в разных зонах доступности или регионах одного облака.
  - В первом — полноценный Patroni HA кластер
  - Во втором — Standby кластер
2. Настройте репликацию и отказоустойчивый DNS (например, с Keepalived или сторонним балансировщиком)
3. Проверьте отказ одного из кластеров и переключение трафика

Дефолт, как будто понимая важность момента, лениво помурлыкал и уютно устроился рядом — теперь это не просто кот, а символ стабильности BananaFlow.
