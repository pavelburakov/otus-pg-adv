# Домашнее задание "Мульти-мастер кластер"

## Цель:
освоить развёртывание и тестирование геораспределённых мульти-мастер баз данных;


## Описание/Пошаговая инструкция выполнения домашнего задания:
Алексей откинулся на спинку кресла, глядя на экран с графиками нагрузки. После успешного запуска отказоустойчивого кластера ситуация стала меняться — нагрузка росла и смещалась по времени и регионам.

— Алексей, у нас проблема. Клиенты из Нью-Йорка, Чикаго и Москвы работают в разное время, но хотят, чтобы данные в базе всегда были свежими и доступными. Нельзя, чтобы из-за этого у кого-то тормозило или данные расходились. Ты сможешь сделать так, чтобы всё работало быстро и без сбоев?

— Вызов принят! — ответил Алексей, щёлкнув пальцами.


## 🛠 Вариант 1: CockroachDB в облаке

1. Разверни CockroachDB в облаке
2. Используй датасет 10 Гб+
3. Сравни производительность запросов с однопользовательским инстансом PostgreSQL
4. Опиши процесс, решения и возникшие сложности

## 🛠 Вариант 2: Геораспределённый PostgreSQL-like сервис

1. Перенеси 10 Гб тестовой БД в геораспределённый кластер PostgreSQL или совместимый сервис
2. Настрой синхронизацию и балансировку нагрузки между регионами
3. Проверь отклик и консистентность данных
4. Опиши весь процесс и проблемы
